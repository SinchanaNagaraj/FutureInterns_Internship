# FutureInterns Internship - UI/UX Projects

This repository contains UI/UX projects completed during the FutureInterns Internship program.

---

## Projects

### 1. FUTURE_UIUX_1 - Digital Restaurant Menu
A digital restaurant menu interface built with React and Vite.

### 2. FUTURE_UIUX_2 - Health Improvement App UI
A health improvement app UI based on the Figma design.  
Original Figma: https://www.figma.com/design/c7Ff4dJIhwIJavYhF4AmTJ/Health-Improvement-App-UI

### 3. FUTURE_UIUX_3 - Freelancer Collaboration Platform
A freelancer collaboration platform UI based on the Figma design.  
Original Figma: https://www.figma.com/design/b9RFbp0iIzHamaaiMdys3A/Freelancer-Collaboration-Platform

---

## Running Each Project

Navigate into any project folder and run:

```bash
npm i
npm run dev
```

## Tech Stack
- React
- TypeScript
- Vite
- Tailwind CSS
